# Agent Workflow

Before editing, read `AGENTS.md` and the relevant subsystem README.

## Change Discipline

- Keep changes scoped to the subsystem requested.
- Avoid broad staging and unrelated cleanup.
- Preserve user-created local evidence unless asked to replace it.
- Record source paths when importing generated artifacts.

## Evidence Discipline

- For model output, store raw JSON or JSONL when possible.
- For deck claims, keep validation scripts close to the deck package.
- For live-demo issues, capture both the symptom and the fix evidence.
