# Safety Boundary

This repository is for research and thesis defense.

Do not state or imply:

- clinical deployment readiness;
- diagnosis from image alone;
- clinician gold-standard adjudication unless a source explicitly supports it;
- three selected cases as an aggregate accuracy estimate.

Prefer:

- "research decision support";
- "silver/reference/pipeline label";
- "post-hoc presentation assessment";
- "image as evidence/context, not standalone proof";
- "aggregate thesis metrics remain the benchmark."
